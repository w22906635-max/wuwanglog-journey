# 无妄的博客搭建历程

记录一个医学生的个人博客是怎么从**别人的开源模板**一步步变成自己的站点的：换了什么、踩了什么坑、最后长成什么样。

- 站点：<https://wuwanglog.com>
- 起点模板：[XHBlogs（XinghuisamaBlogs）](https://github.com/heiehiehi/XinghuisamaBlogs) —— 本仓库**不含**模板源码，只记录改造过程与结论；模板版权与许可见 [CREDITS.md](CREDITS.md)
- 本仓库内容：纯文字复盘 + 运维手册，无站点源码

---

## 一、起点：把别人的模板改成自己的地方

最早是拿 **XHBlogs** 起的站。第一件事不是加功能，而是把别人的痕迹去掉——站点标题、作者名、简介、导航、弹幕文案、友链、项目列表、关于页全部重写；视觉上换掉背景图、头像（兼 favicon）、四张文章默认封面、十张照片墙照片。

这一步里有个小设计：**文章不写封面时，按文件名做哈希，从四张默认封面里稳定轮换**——同一篇文章永远同一张，刷新也不会变。

评论系统从 Gitalk 换成 **Giscus**。原因很实在：Gitalk 要在前端暴露 clientSecret，等于把钥匙挂在门上。

另外接了自己的网易云歌单（随机抽 10 首，每 10 分钟换一批），以及一个叫「令」的猫猫助理——像素立绘加一套说话方式，全站几处都改成了她的口吻。

## 二、长出来的几块东西

**公告页**（2026-10-20）：从 `notices/` 目录读 Markdown，支持置顶；导航加入口，页脚改成三行居中。

**每日拾光**（同日上线）：首页一张宽幅海报卡片，内容是「AI 日报 + 文献雷达」：

- 快讯抓 OpenAI、DeepMind、Anthropic、英伟达等源的 RSS 与 sitemap
- 文献从 Europe PMC 取，固定「医学」「生化科学」两个方向
- 摘要交给 DeepSeek 改写成中文
- 每周一早上 9 点由 GitHub Actions 自动跑，写入 `data/daily.ts`，并维护一份去重台账，避免连着推同一条

**背景轮换**（2026-10-21）：背景图扩到 7 张，每 60 秒换一张，2 秒淡入淡出。

## 三、内容怎么组织

四类内容，四个目录，**文件名就是网址**：

| 栏目 | 目录 | 路由 |
|---|---|---|
| 文章 | `posts/` | `/posts/<slug>` |
| 杂谈 | `chatters/` | `/chatter/<文件名>` |
| 说说 | `moments/` | `/moments` |
| 公告 | `notices/` | `/notice` |

关键点：页面**扫目录自动收录**，新建 md 不需要改任何路由或配置。所以发一篇东西只要写文件 + push。

## 四、怎么上线

链路：**写 md → git push 到 `main` → Vercel 自动构建 → 1~2 分钟生效**。

踩过并固定的规矩：

- 推送要用专门的 SSH 密钥，默认那把推不上去
- **不能 `git add -A`**：仓库里常有别的改动，会一起被带上
- **不能在 Vercel 手动 Redeploy 旧部署**：会把线上顶回旧版本
- 拉取改走「HTTPS + 代理」，推送走 SSH，两条路分工

## 五、本地控制台

为了少开编辑器，做了一个本地控制台（Python + Next.js）：改配置、写文章、管草稿、一键镜像到博客仓库。

两个印象最深的坑：

1. **窗口一直闪**：它用 `npm run dev` 起前端，Next 热重载在反复整页刷新，峰值一秒 1.5 次。改成生产模式（跑构建产物）才安静。
2. **启动即崩**：Windows 下 Python 输出默认 GBK，日志里一个 emoji 就让进程退出，表现是「黑窗一闪就没了」。修法是强制 UTF-8 + `errors='replace'`。

## 六、换域名

最开始用免费域名（DNSHE 的 `wuwangdeboke.us.ci`）。免费域名控制不了 WHOIS，也可能随时回收，于是买了 **`wuwanglog.com`**（Cloudflare Registrar，$10.46/年，买三年，自动续费）。

接入要点：

- Cloudflare 两条记录：`A @ → 76.76.21.21`、`CNAME www → cname.vercel-dns.com`
- 两条都必须是**灰云**（只做 DNS），橙色代理会和 Vercel 的证书打架
- 统一**不带 www**，带 www 的 308 跳过去
- 旧域名保留到 2027 年，只做跳转

同一天加了 **RSS**：`https://wuwanglog.com/feed.xml`，页头带自动发现标签。

## 七、现在的样子

- 站点：Next.js 15 + Vercel，Cloudflare 管 DNS
- 评论：Giscus（挂在单独的 comments 仓库）
- 订阅：RSS
- 自动更新：每周一「每日拾光」自己跑、自己 commit
- 发文：写 md，push 就上线
- 维护：本地控制台管配置与内容

顺手补过一个细节：文章删除后旧链接返回 500（代码直接读文件、读不到就抛异常），加了 `notFound()` 之后变成干净的 404。
