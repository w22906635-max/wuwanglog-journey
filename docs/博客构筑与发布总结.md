## 三、站点是怎么搭起来的

### 1. 基础迁移与个性化（2026-10-11）

- 以 XHBlogs 模板为底，全站去原作者化：标题、作者、bio、导航、弹幕文案、友链、项目、关于页全部改写。
- 视觉资源替换：`public/bg-main.jpg`（背景）、`avatar.jpg`（头像兼 favicon）、`cover1~4`（文章默认封面）、`photos/p01~p10.jpg`（照片墙，长边 1920、质量 85 压到 2.1 MB）。
- 新增按 slug 稳定轮换的默认封面：`siteConfig.defaultPostCovers` + `getDefaultCover(seed)`（FNV-1a 哈希），首页、文章页、杂谈页、时间线四处调用；文章的 frontmatter 不写 `cover` 就走轮换。
- 网易云音乐：`app/api/music/route.ts` 支持歌单模式（`cloudMusicPlaylistId = 4993213701`），先取完整 trackIds 再 Fisher-Yates 随机 10 首，`revalidate = 600` 每 10 分钟换一批。
- 评论：从 Gitalk 迁移到 Giscus（Gitalk 需前端暴露 clientSecret，不安全），删除全部 Gitalk 残留；`components/Comments.tsx` 监听 `html.dark` 联动昼夜模式。
- 猫猫助理「令」：像素立绘 `public/ling.png`，台词与动画全部改成令的口吻（两份文件同步改）。

### 2. 公告页与全站页脚（2026-10-20）

- 新增 `/notice` 公告页，数据来自 `notices/*.md`，字段 `title / date / tag / pinned`；置顶优先，其余按日期倒序。
- 导航栏加入公告入口。
- 全站页脚改成三行居中声明（参考 nicebowl.fun），站点备注可配置。

### 3. 每日拾光：AI 日报 + 文献雷达（2026-10-20 起）

- 首页组件 `components/DailyPoster.tsx`：宽幅海报式开合卡片，封面 `public/daily-cover.jpg`（AI 生成的东方「纯狐」3:1 插画，自托管），左侧渐变叠层保证文字可读。
- 数据在 `data/daily.ts`（最新一期固定放数组第 0 位），去重台账在 `data/daily-history.ts`。
- 内容方向：AI 日报（OpenAI / Google DeepMind / Anthropic 等）+ 文献雷达（固定「医学」与「生化科学」）。
- 文献来源 Europe PMC REST API；AI 快讯来源为 RSS（DeepMind / Google Research / Microsoft Research / NVIDIA / Amazon Science / Hugging Face）+ OpenAI、Anthropic 的 sitemap 抓取（两家无可用 RSS）。
- 摘要由 DeepSeek（OpenAI 兼容接口 `https://api.deepseek.com/v1`，`deepseek-chat`）改写为中文。
- 抓取脚本 `scripts/daily_update.mjs`；工作流 `.github/workflows/daily-update.yml`：每周一 09:00（北京时间，`cron '0 1 * * 1'`）自动跑，也可在 Actions 里 `Run workflow`（`dry_run` 默认 true，只抓不写）。
- 工作流依赖仓库 Secrets `AI_API_KEY`，可选 Vars `AI_BASE_URL` / `AI_MODEL`；失败会自动开 Issue 告警。
- 第一期是手工核实的真实内容：3 条 AI 日报 + 3 篇文献（Lancet / NEJM / Nature），全部保留真实链接与 DOI。

### 4. 背景图轮换（2026-10-21）

- `siteConfig.bgImages` 现为 7 张：`bg-main.jpg` + `bg1~bg6.jpg`。
- `components/BackgroundSlider.tsx` 每 **60 秒** 切换一次（原为 10 秒），2 秒淡入淡出，非当前图 `opacity: 0` 并隐藏相邻以外的层。

## 四、四类内容的目录与 frontmatter

文章、杂谈、公告的 `date` 用北京时间 `'YYYY-MM-DD HH:MM:SS'`（加引号）；说说的 `date` 是 **UTC**。
文件名即网址，文章 / 杂谈 / 公告的文件名只能用英文、数字、连字符。

| 栏目 | 目录 | 命名 | 线上路由 |
|---|---|---|---|
| 文章 | `posts/` | `<英文-slug>.md` | `/posts/<slug>` |
| 杂谈 | `chatters/` | `<YYYY-MM-DD>-<英文词>.md` | `/chatter/<文件名>` |
| 说说 | `moments/` | `moment-<13位数字>.md` | `/moments` |
| 公告 | `notices/` | `<英文-slug>.md` | `/notice` |

**文章**

```markdown
---
title: "标题"
date: "2026-10-20 20:00:00"
description: "一句话摘要，显示在列表卡片上"
tags: ["随笔", "学医日常"]
mood: "平静"
---

正文，支持 Markdown。
```

**杂谈**（不写 `cover` 时首页卡片用一张 unsplash 占位图，建议补 `cover: '/photos/p05.jpg'`）

```markdown
---
title: 标题
date: '2026-10-20 23:40:00'
tags:
- 学医日常
- 胡思乱想
mood: 发呆
description: 一句话摘要
---

正文。
```

**说说**（文件名里的 13 位数字随便取、不重复即可，真实时间以 `date` 为准）

```markdown
---
date: "2026-10-20T15:40:00.000Z"
location: 医院值班室
images:
  - '/photos/p05.jpg'
---

想说的话。
```

UTC 换算：想显示北京时间 10-20 23:40 → 写 `2026-10-20T15:40:00.000Z`（北京时间减 8 小时）。

**公告**

```markdown
---
title: 站点维护通知
date: "2026-10-20"
tag: 维护
pinned: true
---

公告正文。
```

`pinned: true` 置顶。公告页已有 `<h1>公告</h1>` 页头，正文里不要再写同名一级标题。

**配图**：图片放 `public/`（可建子目录，如 `public/photos/`），正文用 `/photos/p01.jpg` 引用，**不要带 `public`**；先压缩，长边 1920、质量 85 足够。

## 五、公告上传完整流程（重点）

以「关于本博客」为例，实际操作如下：

1. **落盘**：在 `notices/` 新建 `<英文-slug>.md`，例如 `notices/about-blog.md`。
2. **写 frontmatter**：`title` 写公告标题；`date` 写发布日（`"2026-10-21"`）；`tag` 写分类（如 `说明` / `维护` / `友链`）；长期有效的公告加 `pinned: true`。
3. **正文**：直接贴 Markdown，代码块、引用、表格都支持；若原文开头是 `# 标题`，删掉这一行，避免和页面标题重复。
4. **推送**（只 add 本次文件）：

```powershell
$git = "C:\Program Files\Git\cmd\git.exe"
$env:GIT_SSH_COMMAND = 'ssh -i "C:/Users/8848tjPC/.ssh/id_ed25519_source" -o IdentitiesOnly=yes -o StrictHostKeyChecking=no'
& $git -C "D:\AIwork space\myblog\XHBlogs" status --short
& $git -C "D:\AIwork space\myblog\XHBlogs" add "notices/about-blog.md"
& $git -C "D:\AIwork space\myblog\XHBlogs" commit -m "公告：<标题>"
& $git -C "D:\AIwork space\myblog\XHBlogs" push origin HEAD:main
```

5. **验证**：等 1~2 分钟，抓 `/notice` 找关键词：

```powershell
Start-Sleep -Seconds 75
$h = (Invoke-WebRequest -Uri "https://wuwanglog.com/notice?v=$((Get-Random))" -UseBasicParsing).Content
if ($h -match "关于本博客") { "已上线" } else { "还没更新" }
```

6. **手机端发公告**：GitHub 手机 App 不能新建文件，必须用手机浏览器打开 `github.com/w22906635-max/my-log` → 切「请求桌面版网站」→ 进 `notices/` → 右上 **Add file → Create new file** → 粘贴模板 → 拉到底 **Commit changes**（提交到 `main`）。

> 目前公告页只有一篇 `notices/about-blog.md`（《关于本博客》，置顶）。`notices/` 里的 `.gitkeep` 只是占位，不是公告。

## 六、日常发布与上线

### 方式 A：直接 git（推荐，AI 一直用这个）

见上面的推送命令；把 `add` 的文件换成本次要发布的 md（可一次 add 多个具体文件）。

推送前必须 `status --short` 看清楚，**禁止 `git add -A`**：仓库里常有他人遗留改动，会被一起带上。

### 方式 B：本地控制台（适合改配置）

流程：保存双轨配置 → 编辑并镜像全景 → 仅同步源码。
控制台 `my-blog-manager/siteConfig.ts` 是配置源头，点「编辑并镜像全景」会覆盖 `XHBlogs/siteConfig.ts`；**不要点「更新到本地」**。若手机或他人改过内容，操作控制台前先 `git pull`。

### 验证

```powershell
curl.exe -s -L "https://wuwanglog.com/?v=<随机数>" | Select-String -Pattern "<slug>"
curl.exe -s -L "https://wuwanglog.com/posts/<slug>"
```

浏览器仍显示旧内容多为本地缓存，强制刷新即可，不要因此重推。

## 七、自动更新（每日拾光）

- 脚本：`scripts/daily_update.mjs`；工作流：`.github/workflows/daily-update.yml`。
- 触发：每周一 09:00（北京时间）自动运行；也可 Actions →「每日拾光 自动更新」→ Run workflow，`dry_run=true` 只抓取不改文件。
- 前置：仓库 Secrets 配 `AI_API_KEY`（DeepSeek）；可选 Vars `AI_BASE_URL`（默认 `https://api.deepseek.com/v1`）、`AI_MODEL`（默认 `deepseek-chat`）。
- 写入：`data/daily.ts` 头部插入新一期；同时向 `data/daily-history.ts` 追加 `recommendedNewsIds` / `recommendedPaperIds` / `recommendedNewsUrls` / `recommendedPaperDois`。
- **手工补一期时必须同时追加台账**，否则下期会重复选中同一条。
- 重跑请用「Run workflow」发起全新运行，不要用旧运行的「Re-run」（会执行旧版本代码）。
- 工作流失败会自动开 Issue。

## 八、必知坑

1. **不要 `git add -A`**：会连带提交遗留改动。
2. **Vercel 不要手动 Redeploy 旧部署**：旧部署会成为最新 production 并顶掉新版本；更新一律靠 push。
3. **两份 `siteConfig.ts` 必须同步改**：`XHBlogs/siteConfig.ts` 与 `my-blog-manager/siteConfig.ts`，只改后者会在同步时丢失。
4. **控制台会覆盖内容**：其 posts / chatters / moments 会整体覆盖，手机改过内容后电脑操作前先 `git pull`。
5. **`*.vercel.app` 国内被墙**，且 Vercel 新 IP `216.198.79.1` 不通，必须用自定义域名 + `76.76.21.21`。
6. **Cloudflare 必须灰色云朵**（仅 DNS），橙色代理会和 Vercel 的 HTTPS 证书冲突。
7. **域名统一不带 www**，评论 OAuth 回调也基于 `https://wuwanglog.com`。
8. 旧域名 `wangdeboke.new.tg` 已作废（`new.tg` 不在公共后缀列表，Cloudflare 无法托管）。
9. **SSH 偶发 `Connection reset ... port 22`**：重试即可。
10. **沙箱可能拦截 Shell 对仓库目录的写盘**：改用 Write / Edit 工具，或用 Python `shutil.copy2` / `subprocess`。
11. **带横杠的媒体文件名可能被拦**：用 `cover1.png` 这类命名。
12. **TypeScript 有 6 个原作者遗留报错**（`app/chatter/page.tsx`、`app/friends/FriendsBoard.tsx`、`app/moments/page.tsx`、`app/music/MusicClient.tsx`、`app/tree/DijiangModel.tsx`），`next.config.ts` 已设 `ignoreBuildErrors: true`，不影响构建。
13. **Gemini 在大陆不可用**（403 / 模型下架），AI 助理已改走 OpenAI 兼容接口（DeepSeek / 智谱）。
14. **友链文案里的域名**：`siteConfig.friendLinkApplyFormat` 曾把 `wuwangdeboke` 误写成 `wuuwangdeboke`，若未修，注意只保留一个 u。
